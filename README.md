# 数学教学岗申请追踪器 · Math Teaching Job Tracker

A single-page tracker for US mathematics teaching and non-research math jobs for the 2026–27 hiring season, with start dates in summer 2027, fall 2027 or later.

Open `index.html` in a browser, or use the GitHub Pages site once Pages is turned on.

## What's in it

- Lecturer, teaching professor and instructor roles, plus community college, university staff, private K-12, curriculum and content development, assessment, math software, Lean, math editing and AI math roles
- Basic mathematics only. Statistics-heavy roles and US-citizen-only roles are left out.
- Each job has its start date, deadline (the last day you can submit, Eastern Time), minimum qualifications, whether ABD or graduating candidates can apply, number of recommendation letters, a visa note and a direct link to the posting.
- Views: table (click column headers to sort either way), kanban, timeline, due soon, new this week, and a separate tenure-track list
- Filters, highlighting for strong matches, and a materials checklist, status and notes for each job

## Saving progress

Opened from a plain web page, your statuses, checklists and notes are saved in that browser's local storage only. They don't sync between devices, and clearing site data erases them.

## Caveat

Entries marked 待核实 haven't been checked against the original posting yet. Always confirm the deadline and requirements on the official page before applying.
